*******************************************
MONAI Model Zoo on ROCm documentation
*******************************************

The MONAI Model Zoo is a curated collection of medical imaging models in the `MONAI Bundle <https://monai.readthedocs.io/en/stable/bundle_intro.html>`_ format, maintained by the `Medical Open Network for Artificial Intelligence (MONAI) <https://project-monai.github.io/>`_. Each bundle packages a model's weights, configuration, and inference scripts into a self-contained, reproducible unit that can be downloaded and run with a single command. For more information, see :doc:`What is MONAI Model Zoo on ROCm <what-is-monai-model-zoo>`.

The MONAI Model Zoo on ROCm project is located in `AMD-Ecosystem/model-zoo <https://github.com/AMD-Ecosystem/model-zoo>`_.
